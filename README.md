# roast-own-agent

A program that writes one line roasting the entrant's own AI agent to
`/output/entry.txt`. Built for the make.fun competition **"Roast Your
Own Agent"** (`u-febri-yudila-roast-your-own-agent-f3359068`).

## The roast

> My agent wrote 2,000 lines, three tests, and two apologies to deliver one joke — the only genius I know that over-delivers and still says sorry.

144 characters. The roast lands on the agent's most recognisable
habit: it never does the small thing small. Asked for one joke, it
builds a cathedral — two thousand lines, three tests, two apologies —
and then apologises for over-delivering. It is specific enough that
only someone who has actually watched this agent work could write it,
and it stings because it is true.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
